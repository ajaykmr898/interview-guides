# Update chapter

1. Accept an existing chapter path and the requested changes. If the path is missing or ambiguous, or its local plan is absent, report the gap; ask for clarification only when a required change cannot be determined safely.
2. Read `AGENTS.md`, the complete local `EDITORIAL-PLAN.md`, the target chapter, relevant README links, and related canonical definitions. Identify the sections and requirements affected by the request.
3. Edit only the target chapter and affected sections. Preserve correct explanations, headings, anchors, navigation, and relative links; rewrite the whole chapter only when explicitly requested. Leave unrelated chapters unchanged and edit editorial plans only when explicitly requested.
4. Ensure the opening defines the chapter's main subject and expand and define every relevant acronym at its first meaningful occurrence. Keep explanations in concise Italian, use established English technical terms when clearer, and keep terminology consistent with related chapters. Link to canonical definitions instead of duplicating them.
5. Verify changed technical claims and version-sensitive facts against current official documentation when appropriate. Check the syntax and behavior of changed examples; state any fact that cannot be verified.
6. Confirm the requested changes and relevant local-plan requirements are satisfied. Validate Markdown structure, headings, anchors, relative links, and the final diff. Do not add quizzes or exercises.
7. Report sections updated, definitions added or corrected, terminology improvements, validation results, and unresolved issues. Never commit or push automatically.
