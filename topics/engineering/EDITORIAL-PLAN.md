## `15-architecture-devops.md` — Engineering e DevOps

**Da coprire:**
- SOLID, DRY, KISS, YAGNI, separation of concerns e dependency inversion.
- Design patterns: Factory, Strategy, Observer, Adapter, Facade, Repository, Singleton; composition vs inheritance.
- Clean Architecture, modular design, feature-based vs layer-based, trade-off e code smells.
- Monorepo/Nx come concetti, microfrontends e vincoli organizzativi.
- Clean Code, refactoring, code review, linting, formatting, static analysis.
- Unit/integration/component/E2E/contract/smoke/regression tests come categorie; test pyramid, mocks/stubs/spies.
- Git: branch, merge, rebase, revert, reset, cherry-pick; PR, commit convention.
- CI/CD, build pipelines, quality gates, Docker basics, release, rollback e environment handling.
- Observability: logging, metrics, tracing, error monitoring; application security e dependency audits.

**Confronti:** merge vs rebase, CI vs CD, unit vs integration vs E2E, monorepo vs multi-repo.
